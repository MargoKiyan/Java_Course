Основні команди Maven:
mvn compile — компіляція проєкту.
mvn test — запуск тестів.
mvn package — упаковка проєкту в JAR або WAR файл.
mvn install — установка пакету в локальний репозиторій.
Основні поля POM:
groupId: Ідентифікатор групи або організації.
artifactId: Ідентифікатор артефакту або модуля.
version: Версія пакету.
